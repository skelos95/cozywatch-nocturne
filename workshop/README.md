# Codice da importare

**[ruang_irama.en-US.workshop](ruang_irama.en-US.workshop)** è l'unico file da copiare nel Workshop. Imposta la lingua testo del client su **English**, apri **Raw** e copia tutto con **Paste Rules**.

Questo file è il runtime globale generato dal sorgente, con il tema **Nocturne** e interfaccia inglese. La versione corrente è **0.8.4**; i tag e gli allegati delle release precedenti conservano i pacchetti storici. Per ripetere una prova identifica il codice con il suo commit.

Il file contiene le regole; mappe, Schermaglia e slot si configurano nella lobby. Al primo spawn trovi **Rites / Controls**: **Crouch + Interact** apre la guida completa.
